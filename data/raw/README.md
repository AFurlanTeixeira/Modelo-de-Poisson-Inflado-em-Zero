`visitas_medicas.csv`: dataset fornecido no enunciado (dado bruto, não
editar/transformar diretamente — transformações ficam em `R/`).

| Coluna | Tipo | Descrição |
|---|---|---|
| `id` | inteiro | Identificador do cliente dentro do perfil (repete entre perfis) |
| `perfil` | texto | Perfil de risco: `baixo`, `medio` ou `alto` |
| `visitas` | inteiro ≥ 0 | Número de consultas médicas no ano |
